## Slide 2: El Problema

La IA actual está rota:

- **Centralizada**: Depende de la nube. Sin internet, no funciona.
- **Costosa**: Cada llamada a la API cuesta dinero recurrente.
- **Sin ética**: No hay filtro moral. La IA ejecuta lo que se le pide.
- **Sin trazabilidad**: No se puede auditar qué hizo ni cuándo.
- **Sin soberanía**: Los datos salen del dispositivo del usuario.

Las soluciones existentes obligan a elegir entre capacidad y soberanía.

---

## Slide 3: La Solución

**Sentra Core** es un motor de IA que funciona **siempre offline**, con **veto humano** y **trazabilidad criptográfica inalterable**.

- **Offline-first**: Toda la inferencia corre en el dispositivo. Sin nube, sin API pay-per-call.
- **Veto humano (MoralNode)**: 4 reglas inquebrantables que bloquean acciones dañinas antes de ejecutarse.
- **Trazabilidad (EVOLIS)**: Hash chain SHA-256 + firmas ECDSA P-256. Cada acción queda registrada e inmutable.
- **Navaja suiza**: 9 modos de operación en un solo motor.
- **BioSoftware**: Optimiza el "hardware biológico" del usuario (coherencia cardíaca, reencuadre cognitivo, neuroplasticidad).

## Slide 6: Tecnología

| Módulo | Función |
|--------|---------|
| **MoralNode** | Filtro ético: no violencia, privacidad, offline, veto humano |
| **EVOLIS** | Hash chain SHA-256 + firmas ECDSA P-256 |
| **BioSoftwareInterface** | Coherencia cardíaca, placebo cognitivo, reencuadre, neuroplasticidad, epigenética |
| **PerceptionEngine** | COCO-SSD offline + anti-paraidolia + detección de camuflaje + ajuste bio-contextual |
| **BacterialGuardian** | Defensa USB + verificación de cadena con lógica ternaria (+1, 0, -1) |
| **SyncManager** | P2P: LoRa, Bluetooth Mesh, Syncthing |
| **VoiceManager** | Voz bilateral (TTS + STT) con normalización de acentos |
| **GeminiService** | IA generativa con fallback local + cache offline |

Stack: TypeScript · React · Flutter (Dart) · Node.js · TensorFlow.js · WebUSB · Web Bluetooth
